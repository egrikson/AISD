## 2. Используемые алгоритмы и структуры данных

### 2.1. Структуры данных

| Структура | Где используется | Обоснование выбора |
|---|---|---|
| `numpy.ndarray` | матрицы признаков, веса модели, градиенты | непрерывный блок памяти, доступ по индексу за O(1), векторизованные операции выполняются в скомпилированном коде |
| `pandas.DataFrame` | исходные данные, таблицы результатов | удобные именованные столбцы, группировки, чтение и запись CSV |
| `list[dict]` | история обучения (по одной записи на итерацию) | дешёвое добавление в конец за O(1), затем однократное преобразование в `DataFrame` |
| `dict` | сопоставление «имя класса → индекс», параметры экспериментов | доступ по ключу за O(1) в среднем |
| `dataclass` (`Dataset`, `Rule`, `Condition`, `TreeResult`) | абстрактные типы данных предметной области | АТД описывает *что* хранится и какие операции допустимы, скрывая представление |
| упорядоченный список правил | классификатор «если–то» | правила применяются по порядку, первое сработавшее определяет класс |
| дерево (внутри `DecisionTreeClassifier`) | дерево решений | путь от корня к листу — это готовое интерпретируемое правило |

Разделение на **АТД** и **структуру данных** в работе видно на примере класса
`Dataset`: снаружи это «набор размеченных объектов» с операциями
`class_balance()`, `y_encoded()`, а внутри — `DataFrame` и `Series`.

### 2.2. Классификация по правилам, заданным вручную

Правило — конъюнкция элементарных условий «признак ⊗ порог». Пороги выбраны по
результатам разведочного анализа: берутся признаки с наибольшим корреляционным
отношением η², и по гистограммам/диаграммам рассеяния находится значение,
разделяющее классы.

Классификация объекта — линейный проход по списку правил до первого
сработавшего: **O(r · c)**, где r — число правил, c — число условий в правиле.
Обучения нет вообще, поэтому это самый быстрый и самый интерпретируемый
из рассмотренных методов.

### 2.3. Дерево решений

Используется `sklearn.tree.DecisionTreeClassifier` (критерий Джини). Алгоритм
CART жадно выбирает признак и порог, максимизирующие уменьшение неоднородности:

Gini(S) = 1 − Σ pᵢ², где pᵢ — доля объектов класса i в узле S.

* сложность обучения: **O(n · m · log n)** (n — объектов, m — признаков);
* сложность классификации одного объекта: **O(h)**, h — глубина дерева;
* память: O(числа узлов).

Параметр `max_depth` напрямую управляет компромиссом «недообучение —
переобучение»: чем глубже дерево, тем точнее оно на обучающей выборке и тем
выше риск запомнить шум.

### 2.4. Линейная и softmax-регрессия (реализованы вручную)

Обе модели линейны по параметрам: z = X·W, где W имеет размер (m + 1) × k
(последняя строка — свободный член). Различаются функцией потерь:

* **линейная регрессия (MSE)** на one-hot кодированные метки:
  L = (1/n) Σ ‖z − Y‖²; класс = argmax z;
* **softmax-регрессия (log-loss)**: p = softmax(z),
  L = −(1/n) Σ Σ Y·ln p; класс = argmax p.

Обучение — пакетный градиентный спуск: на каждой итерации
W ← W − η · ∇L, где ∇L = c · Xᵀ(выход − Y) / n (c = 2 для MSE, c = 1 для
softmax). Признаки предварительно стандартизуются (z = (x − μ)/σ), иначе
признаки с большим масштабом (например, `proline` в Wine) подавляют остальные,
и спуск расходится.

* сложность обучения: **O(iterations · n · m · k)**;
* сложность предсказания: **O(m · k)** на объект;
* память: O(n · m) на данные и O(m · k) на веса.

Реализация softmax численно устойчива: перед экспонированием из каждой строки
вычитается её максимум.

### 2.5. Метрики и индикаторы сходимости

* **Accuracy** = доля верных ответов;
* **Precision** класса i = TPᵢ / (TPᵢ + FPᵢ), в отчёте используется
  macro-усреднение по классам;
* **‖W‖₂** — «размер» модели; стабилизация нормы означает, что обучение
  завершается, резкий рост — расходимость (взрыв градиентов);
* **‖ΔW‖₂** — длина шага в пространстве параметров; стремление к нулю —
  признак сходимости, именно по этой величине удобно настраивать early stopping.

Все метрики реализованы вручную на NumPy и в тестах сверены с `scikit-learn`.

### 3.2. Правило как структура данных

```python
@dataclass
class Rule:
    """Правило: конъюнкция условий и предсказываемый класс."""

    conditions: list[Condition]
    target: str
    comment: str = ""
    _fired: int = field(default=0, init=False, repr=False)

    def mask(self, X: pd.DataFrame) -> np.ndarray:
        """Булева маска объектов, для которых выполнены все условия."""
        result = np.ones(len(X), dtype=bool)
        for condition in self.conditions:
            result &= condition.evaluate(X[condition.feature])
        return result

    def __str__(self) -> str:
        body = " AND ".join(str(c) for c in self.conditions)
        text = f"ЕСЛИ {body} ТО {self.target}"
        return f"{text}   # {self.comment}" if self.comment else text
```

### 3.3. Применение правил (первое сработавшее правило определяет класс)

```python
    def predict(self, X: pd.DataFrame) -> np.ndarray:
        """Применяет правила по порядку; первое сработавшее задаёт класс."""
        predictions = np.full(len(X), self.default_class, dtype=object)
        assigned = np.zeros(len(X), dtype=bool)
        for rule in self.rules:
            mask = rule.mask(X) & ~assigned
            rule._fired = int(mask.sum())
            predictions[mask] = rule.target
            assigned |= mask
        return predictions.astype(str)
```

### 3.4. Обучение линейной модели градиентным спуском

```python
    def fit(
        self,
        X_train: np.ndarray,
        y_train: np.ndarray,
        X_test: np.ndarray | None = None,
        y_test: np.ndarray | None = None,
    ) -> "GradientDescentClassifier":
        """Обучает модель и заполняет историю обучения по итерациям."""
        Xb = self._prepare(X_train, fit=True)
        Y = self._one_hot(y_train)
        y_train = np.asarray(y_train, dtype=int)
        n_samples = Xb.shape[0]

        rng = np.random.default_rng(self.random_state)
        self.W = rng.normal(scale=0.01, size=(Xb.shape[1], self.n_classes))
        self.history = []

        has_test = X_test is not None and y_test is not None
        if has_test:
            Xb_test = self._prepare(X_test, fit=False)
            Y_test = self._one_hot(y_test)
            y_test = np.asarray(y_test, dtype=int)

        for iteration in range(1, self.n_iterations + 1):
            output = self._forward(Xb)

            # Градиент по форме одинаков для MSE (с множителем 2) и softmax.
            error = output - Y
            scale = 2.0 if self.loss == "mse" else 1.0
            grad = scale * (Xb.T @ error) / n_samples
            if self.l2 > 0:
                grad[:-1] += 2 * self.l2 * self.W[:-1]

            step = self.learning_rate * grad
            self.W -= step

            # --- запись истории обучения после шага ---
            output = self._forward(Xb)
            y_pred = output.argmax(axis=1)
            record: dict[str, float] = {
                "iteration": iteration,
                "train_loss": self._loss_value(output, Y),
                "train_accuracy": self.metrics.accuracy(y_train, y_pred),
                "train_precision_macro": self.metrics.macro_precision(y_train, y_pred),
                "weight_norm_l2": float(np.linalg.norm(self.W)),
                "weight_update_norm_l2": float(np.linalg.norm(step)),
            }
            if has_test:
                out_test = self._forward(Xb_test)
                y_pred_test = out_test.argmax(axis=1)
                record["test_loss"] = self._loss_value(out_test, Y_test)
                record["test_accuracy"] = self.metrics.accuracy(y_test, y_pred_test)
                record["test_precision_macro"] = self.metrics.macro_precision(y_test, y_pred_test)
                for name, value in zip(
                    self.class_names, self.metrics.precision_per_class(y_test, y_pred_test)
                ):
                    record["test_precision_" + name] = float(value)
            self.history.append(record)

        return self
```

### 3.5. Вычисление precision по классам

```python
    def precision_per_class(self, y_true: np.ndarray, y_pred: np.ndarray) -> np.ndarray:
        """Точность по каждому классу: TP / (TP + FP)."""
        cm = self.confusion_matrix(y_true, y_pred)
        predicted = cm.sum(axis=0)          # сколько раз класс был предсказан
        true_positive = np.diag(cm)
        with np.errstate(divide="ignore", invalid="ignore"):
            precision = np.where(predicted > 0, true_positive / np.maximum(predicted, 1), 0.0)
        return precision.astype(float)
```

```python
    def run(
        self,
        X_train: np.ndarray,
        y_train: np.ndarray,
        X_test: np.ndarray,
        y_test: np.ndarray,
    ) -> list[TreeResult]:
        """Обучает по дереву на каждую глубину из self.depths."""
        self.results = []
        for depth in self.depths:
            model = DecisionTreeClassifier(
                max_depth=depth,
                criterion=self.criterion,
                random_state=self.random_state,

            result = TreeResult(
```

2. **Ручные правила — сильный базовый метод.** На хорошо разделимых данных 2–3
   правила по важнейшим признакам дают точность, сравнимую с обученными
   моделями, при нулевом времени обучения. Их недостаток — пороги приходится
   подбирать человеку, и они не переносятся на другие данные.

3. **Дерево решений оказалось самым удобным методом** для этих задач: оно не
   требует стандартизации признаков, обучается за миллисекунды и выдаёт готовые
   правила, которые можно прочитать. Ограничение глубины — главный инструмент
   борьбы с переобучением: на Iris дерево глубины 3 работает на тесте лучше,
   чем дерево без ограничений, хотя на обучающей выборке хуже.

4. **Линейные модели требуют аккуратной настройки.** Без стандартизации
   признаков градиентный спуск на Wine расходится. Функция потерь MSE проигрывает
   перекрёстной энтропии: линейная регрессия на one-hot метках систематически
   уступает softmax-регрессии, потому что штрафует и правильные, но «слишком
   уверенные» ответы.

5. **Графики сходимости говорят о состоянии обучения больше, чем одна метрика.**
   Убывающая функция потерь показывает, что модель учится; стабилизация ‖W‖ —
   что веса перестали расти; стремление ‖ΔW‖ к нулю — что модель сошлась и
   дальнейшие итерации бессмысленны (критерий для early stopping). На Iris за
   100 итераций ‖ΔW‖ ещё не достигла нуля, то есть модель недоучена, и это
   объясняет её отставание от дерева.

6. **Интерпретируемость и точность — разные свойства.** Самая интерпретируемая
   модель (правила и дерево) здесь оказалась и самой точной, но это особенность
   хорошо разделимых табличных данных небольшого размера; на данных высокой
   размерности выбор обычно противоположный.

7. **Сложность алгоритмов подтверждается замерами:** классификация по правилам —
   O(r·c) без обучения, дерево — O(n·m·log n) на обучение и O(h) на предсказание,
   градиентный спуск — O(iterations·n·m·k), и именно он оказался самым медленным
   из трёх подходов.

## 9. Приложение: ответы на контрольные вопросы

**Чем алгоритм отличается от программы?** Алгоритм — это конечная
последовательность однозначных действий, решающая задачу; программа — запись
алгоритма на конкретном языке для конкретного исполнителя. Один алгоритм можно
реализовать множеством программ.

**Свойства классического алгоритма и их аналоги в ML.** Дискретность →
итеративность; конечность → сходимость (качество растёт с числом итераций, но
точного «конца» может не быть); детерминированность → вероятностность;
результативность → приближение к оптимуму; массовость → обобщающая способность
и масштабируемость; понятность → интерпретируемость.

**Что такое сходимость ML-алгоритма?** Приближение к оптимуму по мере роста
числа итераций. В работе она видна по трём графикам: убывающий loss,
стабилизирующаяся ‖W‖, стремящаяся к нулю ‖ΔW‖.

**Что такое early stopping?** Остановка обучения до формального достижения
минимума — когда качество на отложенной выборке перестаёт расти. Практический
критерий — ‖ΔW‖ меньше заданного порога.

**Что такое переобучение?** Модель запоминает шум обучающей выборки вместо
закономерности; train accuracy растёт, test accuracy падает. В работе это видно
на деревьях глубины 5 и больше для Iris.

**Как хранится массив и связанный список?** Массив — непрерывный блок памяти,
адрес элемента вычисляется как `начало + индекс · размер`, доступ за O(1).
Связанный список — узлы с указателями, доступ по индексу за O(n).

**Почему в ML используют NumPy, а не списки Python?** Массив NumPy хранит
однотипные значения в непрерывной памяти, операции векторизованы и выполняются
в скомпилированном коде; список Python хранит указатели на объекты, что дороже
и по памяти, и по времени.

**Какая структура данных использована для истории обучения?** Список словарей
(`list[dict]`), по одной записи на итерацию, с последующим преобразованием в
`pandas.DataFrame` — добавление в конец списка стоит O(1).

**Что такое АТД и чем он отличается от структуры данных?** АТД описывает
поведение (какие операции допустимы), структура данных — реализацию (как именно
всё хранится). Пример из работы: `Dataset` как АТД «размеченная выборка» поверх
`DataFrame`.

**Как стек, очередь и дек применяются в ML?** Стек — хранение промежуточных
значений при обратном распространении ошибки; очередь — загрузка батчей
(DataLoader) и replay buffer в обучении с подкреплением; дек — скользящее окно
по временному ряду.

**Сложность бинарного поиска и почему он неэффективен в связанном списке.**
O(log n) при условии отсортированности массива, так как работает стратегия
деления пополам. В связанном списке переход к среднему элементу стоит O(n),
поэтому суммарно получается O(n log n) — хуже обычного линейного поиска.

**Сложность поиска максимума.** В упорядоченном массиве — O(1) (первый или
последний элемент), в неупорядоченном — O(n).

**Что такое loss-функция и зачем её график?** Мера расхождения предсказаний с
истиной. График показывает, идёт ли обучение: если loss не убывает, модель не
учится (слишком малый шаг, ошибка в градиенте или неподходящие признаки).

**Что такое accuracy и precision?** Accuracy — доля верных ответов по всем
классам. Precision класса — какая доля объектов, отнесённых моделью к этому
классу, действительно ему принадлежит. Precision для *setosa* равна 1.00: модель
ни разу не назвала *setosa* объект другого вида.

**Что показывают ‖W‖ и ‖ΔW‖?** ‖W‖ — «размер» модели: стабилизация означает
завершение обучения, резкий рост — расходимость. ‖ΔW‖ — скорость движения в
пространстве параметров: стремление к нулю означает сходимость.

**Какая модель интерпретируемее и почему?** Дерево решений: путь от корня к
листу читается как готовое правило «ЕСЛИ … И … ТО класс». У линейной модели
интерпретируются лишь веса, и то только после стандартизации признаков.

**В каких задачах важнее интерпретируемость, а в каких точность?**
Интерпретируемость — в медицине, кредитном скоринге, юриспруденции, где решение
нужно обосновать; точность — в распознавании образов, речи, машинном переводе.
